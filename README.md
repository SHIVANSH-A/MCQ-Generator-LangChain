# 🧠 MCQ Generator using LangChain

Generate intelligent and contextual multiple-choice questions (MCQs) from any text using the power of **LangChain** and **LLMs (Large Language Models)**. This project offers a simple yet effective interface to automate MCQ generation, useful for educators, e-learning platforms, and students.

---

## 🚀 Features

- ✅ Extracts relevant questions from any input text
- ✅ Uses LangChain for chaining prompts and managing LLM interactions
- ✅ Generates MCQs with options and correct answers
- ✅ Streamlined prompt design for consistency and quality
- ✅ Easy to customize for different subjects or difficulty levels

---

## 🧰 Tech Stack

- **Python 3.8+**
- [LangChain](https://www.langchain.com/)
- [OpenAI API](https://platform.openai.com/)
- Streamlit (optional, for web UI)
